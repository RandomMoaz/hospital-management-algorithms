# 🏥 Hospital Management System

A simple **Hospital Management System** built using **Java** 💻
This project demonstrates the use of **data structures, sorting, and searching algorithms**.

---

## 📌 Features

* ➕ Add Hospitals
* 👨‍⚕️ Add Doctors
* 🧑‍🤝‍🧑 Add Patients
* 🔄 Sort Hospitals by Name
* 🔢 Sort Doctors by ID
* 🔢 Sort Patients by ID
* 🔍 Search Doctors by Specialty
* 🔎 Search Patients by ID

---

## 🧠 Concepts Used

* 📚 Object-Oriented Programming (OOP)
* 📦 ArrayList (Dynamic Arrays)
* 🔄 Sorting Algorithms
* 🔍 Searching Algorithms
* 🖥️ Console-based UI

---

## 🛠️ Technologies

* ☕ Java
* 📟 CLI (Command Line Interface)
